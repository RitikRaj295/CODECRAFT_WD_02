# ⏱️ Stopwatch App

A simple and interactive stopwatch web application built using **HTML**, **CSS**, and **JavaScript**. This app allows users to **start**, **stop**, **reset** the timer, and **save lap times**, which are displayed in a lap list. Font Awesome icons are used to enhance the visual appearance of the control buttons.

## 🚀 Live Demo

🔗 [Click here to view the live app](https://ritikraj295.github.io/CODECRAFT_WD_02/)

## ✨ Features

- ✅ Start, Stop, and Reset the timer
- 🕒 Save lap times with real-time precision
- 📋 View all saved lap times in a Lap List component
- 🎨 Clean and responsive design
- 🔣 Font Awesome icons for a modern UI experience

## 🛠️ Tech Stack

- **HTML5**
- **CSS3**
- **JavaScript (ES6)**
- **Font Awesome**
